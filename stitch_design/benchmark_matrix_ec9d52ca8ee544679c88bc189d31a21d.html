Distinguishing Individual Inference Confidence vs. Verified Test Accuracy

Important distinction for scientific practitioners:

Individual prediction confidence represents the softmax probability output of a model on a single input image (P(y = c | x)). In contrast, Test Set Accuracy (Top-1 / Top-5) represents the verified empirical performance across thousands of unseen test specimens with known ground-truth labels (N=4,548). A model may output a 99.2% softmax probability on an anomalous specimen while maintaining an 89.6% aggregate benchmark accuracy across the taxonomic distribution.
Per-Inference Softmax Output Local Posterior Distribution

Vulnerable to calibration drift, out-of-distribution artifacts, and extreme ocean water turbidity.

Holdout Empirical Accuracy Global Generalization Capacity

Determined exclusively via ground-truth specimen validation over the 4,548 multi-class test split.
